# Audit Record Schema

## Finding

Required fields:

- ID
- STATUS: CANDIDATE | CONFIRMED | REJECTED | INCONCLUSIVE | FIXED | VERIFIED | OPEN
- SEVERITY
- SCOPE
- LOCATION
- CLAIM
- EXPECTED
- OBSERVED
- EVIDENCE
- REPRODUCTION
- ROOT_CAUSE
- RELATED_PATTERN
- AFFECTED_INSTANCES
- FIX
- REGRESSION_TEST
- VERIFICATION
- REMAINING_RISK

## Pattern

Required fields:

- PATTERN_ID
- ROOT_CAUSE_PATTERN
- ORIGIN_FINDING
- SEARCH_METHOD
- CANDIDATES
- CONFIRMED_SIBLINGS
- REJECTED_SIBLINGS
- OPEN_QUESTIONS

Keep records concise. Link to files/commands instead of embedding large output.
