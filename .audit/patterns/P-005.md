# P-005 — JSON feature-vector contract bypassed by raw-text fallback writers

- PATTERN_ID: P-005
- ROOT_CAUSE_PATTERN:
  `feedback_training_samples.feature_vector` is documented as JSON
  (db/models.py:335; the retraining gate requires `len(json.loads(v)) == 6`,
  scripts/train_models_from_logs.py:163-171). Two fallback paths write the raw
  window title / context string instead of the serialized 6-vector:
  tracking/activity_monitor.py:61 (`json.dumps(features) if features else (context or "")`)
  and web/api.py:74-82 (verbatim copy of that value). The stored value is a valid
  String but invalid JSON; the consumer silently skips it, dropping real user
  corrections from retraining.
- ORIGIN_FINDING: FKT-F-005
- SEARCH_METHOD:
  - grep `context_keywords|feature_vector|json.dumps|json.loads|\.tags` (28+53
    hits); read every writer, reader, and consumer plus related tests.
- CANDIDATES:

    `''a,b''` into context_keywords (test-side mask of the invariant, not a
    production sibling; evidence of why tests miss the defect).
- CONFIRMED_SIBLINGS:

    instances (verified verbatim copy chain end-to-end).
