# P-001 — Import-time capture of a rebindable runtime dependency

- PATTERN_ID: P-001
- ROOT_CAUSE_PATTERN:
  Rebindable runtime dependency (`models.engine` / `models.SessionLocal`) captured by
  value at module import time. Function-scope importers (`from tracker_app.db.models
  import SessionLocal` inside a function) re-resolve the attribute at call time and
  see rebinds; module-scope importers keep the stale binding forever. Any rebind
  (test override, runtime re-point of the engine/session) silently bypasses the
  module-scope importer.
